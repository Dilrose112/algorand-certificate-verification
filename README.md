# Algorand Certificate Verification System

A blockchain-based certificate verification system built using Algorand.

## Objective

To provide a secure and tamper-resistant way to issue and verify
educational certificates using the Algorand blockchain.

## Planned Features

- Certificate issuance
- Certificate verification
- Blockchain-based certificate records
- Unique certificate ID
- Tamper detection

## Technology

- Algorand
- Algorand SDK
- Python
- Algorand TestNet
